# Website themes

Available themes:

- `vivid-cloud` — the bright, high-contrast cloud design
- `aurora-mist` — the cooler periwinkle, lavender and glass-cloud design

From the `new` website folder, run:

```bash
bash theme.sh vivid-cloud
bash theme.sh aurora-mist
```

To see the available names and the currently selected theme:

```bash
bash theme.sh list
```

The script changes only the theme stylesheet reference in the HTML pages. It
does not alter or delete either theme.
